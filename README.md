This is a template for a PhD thesis following the format of Faculty of Medicine at Heinrich Heine University Düsseldorf. 

# Usage

- In `main.bib` set the title, your name
Adapt title, name, etc and set up citations in main.bib
Change content with Lorep Ipsum in the documents
Add the paper PDFs (if you want)

Actual content is in subfolders, and is imported by `main.tex`.

The frontmatter is adapted to thesis submission to the Saarland University, Saarbruecken in Germany. The `main.tex` holds the top-level structure of the thesis. Each chapter has its own folder which could be individual papers. The `main.bib` is created by adding references from all chapter-specific bib files. This is then sorted and any duplicates are removed.
